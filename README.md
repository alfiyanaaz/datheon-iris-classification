Iris Classification Pipeline

Project Overview

This project implements a machine learning classification pipeline using the Iris dataset. It compares Logistic Regression and Decision Tree classifiers to predict iris flower species.

Objectives

- Load and explore the Iris dataset.
- Split data into training and testing sets using an 80:20 ratio.
- Train Logistic Regression and Decision Tree models.
- Evaluate models using Accuracy, Precision, Recall, and F1-score.
- Visualize confusion matrices and compare model performance.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Files

- "iris_classification.py" — Python implementation.
- "Iris_Classification_Pipeline.ipynb" — Jupyter Notebook.
- "classification_results.csv" — Model evaluation results.
- "iris_pairplot.png" — Dataset visualization.
- "model_comparison.png" — Model performance comparison.
- "logistic_regression_confusion_matrix.png" — Logistic Regression evaluation.
- "decision_tree_confusion_matrix.png" — Decision Tree evaluation.

How to Run

1. Install the required libraries:
   "pip install pandas scikit-learn matplotlib seaborn jupyter"
2. Run the Python script:
   "python iris_classification.py"

Evaluation

Both classifiers are evaluated on the test dataset using standard classification metrics. The results and visualizations help compare their performance.
